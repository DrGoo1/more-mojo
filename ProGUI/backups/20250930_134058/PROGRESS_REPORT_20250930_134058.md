## Technical Architecture

### ISPInfoComponent Class
**Location**: Lines 1536-1834 in `UIDemoComponent.cpp`

This shared component provides:
- **Smart dispatching** based on process name (ISP, SRC, JITTER, ALIGN)
- **Rich text content** via `getProcessInfo()`
- **Sophisticated graphics** via `drawGraphics()` dispatcher
- **Specialized graphics methods**:
  - `drawFrequencyResponse()` - For SRC and ISP
  - `drawWaveformWithPeaks()` - For JITTER
  - `drawOversamplingComparison()` - For ISP
  - `drawResolutionExample()` - For ISP
  - `drawJitterGraphics()` - Placeholder for JITTER-specific graphics
  - `drawSRCGraphics()` - Placeholder for SRC-specific graphics
  - `drawAlignGraphics()` - Placeholder for ALIGN-specific graphics

### Design Pattern
All four control windows (ISP, SRC, JITTER, ALIGN) now use the same pattern:
1. INFO button in UI
2. `onClick` handler calls `showInfoWindow()`
3. `showInfoWindow()` creates `ISPInfoComponent` with process name
4. Modal dialog displays component with appropriate content and graphics
5. User can resize, read, and close dialog
